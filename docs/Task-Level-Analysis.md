# Example Deliverable
## Task-Level AI Opportunity Analysis

One of the core workshop activities is a **task-level AI opportunity analysis**.

Rather than discussing AI in general terms, participants work with structured reports generated from occupational task data. These reports help learners evaluate **individual work tasks** and decide where AI can automate, augment, or should remain under human control.

The objective is not to recommend AI indiscriminately.

The objective is to support informed decision making.

---

# What Participants Analyse

Each participant receives a task-specific report containing structured information such as:

- Occupational role
- Individual work tasks
- Task characteristics
- AI suitability indicators
- Recommended AI role
- Human oversight requirements
- Potential risks
- Suggested AI tool category
- Confidence indicators

The reports provide a practical basis for discussion and workflow design throughout the workshop.

---

# Example

The example below shows a small extract from the report used for the occupation:

**Treasurers and Controllers (O*NET 11-3031.01)**

| Task | Recommendation | Human Role |
|------|----------------|------------|
| Prepare financial reports | Mixed workflow | Final approval and review |
| Develop internal control policies | Augment | Review AI outputs and apply judgement |
| Monitor accounting standards | Augment | Contextual review |
| Analyse financial operations | Automate selected sub-tasks | Exception handling |
| Advise management | Augment | Strategic judgement |
| Conduct audits | Human Control | Full accountability |

---

# How the Report Supports Learning

Participants use the report to discuss questions such as:

- Which tasks are repetitive?
- Which require human judgement?
- Where can AI improve productivity?
- Which tasks involve higher organisational risk?
- What level of human oversight is appropriate?
- Which AI tool category best supports this task?
- How should an AI-assisted workflow be designed?

Rather than teaching generic prompting techniques, the workshop begins with real workplace tasks and encourages participants to make informed decisions based on their own professional context.

---

# From Analysis to Action

The task-level report is only the starting point.

Participants use the analysis to:

1. Select a task.
2. Identify an AI opportunity.
3. Choose an appropriate AI tool.
4. Design prompts.
5. Evaluate AI outputs.
6. Document an AI-supported workflow.
7. Create an adoption plan.

This reflects the workshop's guiding principle:

**Work Task → Opportunity → AI Tool → Prompt → Evaluation → Workflow → Adoption**
