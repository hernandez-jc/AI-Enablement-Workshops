# Moodle Learning Environment

The workshop is supported by a MoodleCloud learning environment designed to extend learning beyond live facilitation.

Rather than acting as a repository for presentation slides, the platform encourages participants to analyse tasks, experiment with AI, document workflows, and reflect on their decisions throughout the learning journey.

The objective is to create an environment where participants actively build AI capability rather than passively consume information.

---

# Interactive Task Analysis Workspace

![Task Analysis Workspace](../images/TaskLenseAI.jpg)

One of the core workshop activities uses an interactive task analysis workspace.

Participants either:

- select an occupational profile,
- load an example role,
- or paste their own workplace tasks.

The environment analyses each task individually and provides structured recommendations to support discussion and workflow design.

---

# What Participants See

For every task, participants receive practical guidance including:

- AI recommendation
- Automation potential
- Augmentation potential
- Human control requirements
- High-risk indicators
- Task-by-task reasoning profile

Rather than producing a simple "AI can do this" recommendation, the analysis encourages participants to evaluate where AI should support work and where professional judgement should remain central.

---

# Example Learning Activity

A participant working in Human Resources may analyse tasks such as:

- drafting job descriptions
- reviewing applicant resumes
- entering payroll information
- conducting conflict resolution meetings
- approving employee terminations

Each task receives an independent recommendation.

Some tasks may be suitable for augmentation.

Others require significant human oversight.

Participants compare these recommendations with their own experience before designing AI-supported workflows.

This creates opportunities for discussion, reflection, and informed decision making.

---

# Supporting Facilitation

The workspace is not intended to replace professional judgement.

Instead, it provides a structured starting point for facilitated discussion.

Typical questions include:

- Which recommendations surprised you?
- Which tasks should remain under human control?
- Where could AI improve efficiency?
- Which recommendations require organisational policies?
- What additional safeguards would you introduce?

These conversations help participants understand that successful AI adoption depends on context, judgement, and responsible implementation rather than technology alone.

---

# Learning Through Exploration

The workshop follows a learner-centred philosophy.

Participants explore.

They question.

They compare.

They test.

The facilitator guides the discussion rather than providing predetermined answers.

This approach encourages deeper understanding and greater confidence when applying AI within real workplace settings.

---

# From Analysis to Adoption

The task analysis workspace provides the evidence that participants use to build practical AI-supported workflows.

Instead of asking,

*"What can this AI tool do?"*

participants ask,

*"How can this task be improved while maintaining appropriate human oversight?"*

That shift reflects the guiding principle of the workshop:

**Work Task → Opportunity → AI Tool → Prompt → Evaluation → Workflow → Adoption**
